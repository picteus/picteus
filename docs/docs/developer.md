# Developer documentation

The developer documentation explains how Picteus is structured, built, tested, and delivered. Use it when working on the Picteus source code, its build system, or its continuous integration workflows.

## Documentation in this section

- [Architecture](developer/architecture.md) — understand the main application components, their boundaries, and how they work together;
- [Build](developer/build.md) — build Picteus and its workspaces locally and understand the required development commands;
- [CI/CD](developer/ci-cd.md) — review the continuous integration and delivery workflows used to validate and publish changes.

## Guidance

Start with [Architecture](developer/architecture.md) when you need to locate a change or understand a cross-component dependency. Read [Build](developer/build.md) before modifying tooling or validating a local change. Use [CI/CD](developer/ci-cd.md) to check how a change is validated in automation and how releases are produced.
