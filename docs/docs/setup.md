# Setup documentation

The setup documentation covers the steps required to install Picteus, start it, prepare its file system, inspect traces, and resolve common installation or runtime problems.

## Documentation in this section

- [Installation](setup/install.md) — install Picteus and its required components;
- [Starting Picteus](setup/start.md) — launch the application and verify that it is available;
- [Files](setup/files.md) — understand the directories and files used by Picteus;
- [Traces](setup/traces.md) — locate and interpret application logs and diagnostic traces;
- [Troubleshooting](setup/troubleshooting.md) — diagnose common setup and runtime issues.

## Guidance

Follow [Installation](setup/install.md) first, then use [Starting Picteus](setup/start.md) to verify the installation. Read [Files](setup/files.md) when configuring paths, backups, or mounted storage. Consult [Traces](setup/traces.md) before troubleshooting, and use [Troubleshooting](setup/troubleshooting.md) for issue-specific checks.
