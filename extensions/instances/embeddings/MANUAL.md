# Summary
This extension computes vectorial embeddings for every indexed image and stores it.

# Settings
- `CLIP` specifies whether the "[CLIP](https://github.com/openai/CLIP)" Vision Model should be used to compute an embedding for an image.
- `DINO` specifies whether the "[DINO](https://github.com/facebookresearch/dinov2)" Vision Model should be used to compute an embedding for an image
