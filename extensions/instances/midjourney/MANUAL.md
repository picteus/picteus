# Summary
This extension connects Picteus with [Midjourney](https://www.midjourney.com).

It provides the following capabilities:
- opening the [Midjourney](https://www.midjourney.com) web application directly from the sidebar ;
- automatically provisioning and watching a dedicated "Midjourney" image repository ;
- importing images generated by the authenticated Midjourney account as soon as the sidebar is opened and the user is logged in ;
- extracting generation instructions and command parameters — such as prompt text, model version, aspect ratio, stylization, chaos, weirdness, quality, and seeds — from image metadata ;
- creating a generation recipe conforming to the recipe schema, tagging images with `midjourney`, and storing the prompt description ;
- presenting all parsed generation parameters as a structured metadata overview in the image detail view.

Already generated images in Midjourney are automatically imported into the "Midjourney" repository as soon as the sidebar panel is opened and the user is authenticated against Midjourney.

# Prerequisites
An active account on [Midjourney](https://www.midjourney.com) with an active subscription is required to access the service and generate images.
