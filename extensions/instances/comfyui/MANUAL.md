# Summary
This extension offers a bridge between Picteus and [ComfyUI](https://github.com/comfy-org/comfyui) or [Comfy Desktop](https://comfy.org).

- Whenever an image is indexed, if that image was generated via ComfyUI / Comfy Desktop, it stores its generation workflow in the database, which is accessible from an image detail page. This does not require any other third-party software, and it works even if ComfyUI / Comfy Desktop is not installed.

If Comfy Desktop is installed, up and running:
- it integrates the ComfyUI workflow editor via a dedicated sidebar window in Picteus ;
- it enables to open the generation workflow of an image that was generated by ComfyUI, via the "Edit" command.

# Prerequisites
If you want to be able to interact with the ComfyUI / Comfy Desktop application, before starting using this extension, you need to have:
- either your ComfyUI application properly configured, 
- or your Comfy Desktop application properly configured.
The ComfyUI / Comfy Desktop application must be up and running.

## ComfyUI
Inspect the 2 following ComfyUI CLI command options:
1. `--port <portNumber>`: this specifies the internet back-end HTTP port number listens to, where `<portNumber>` is the value of that port number, implicitly defaulted to `8188` ;
2. `--enable-cors-header [origin]`: this enables Cross-Origin Resource Sharing (CORS), where `[origin]` is the authorized domain — a `*` value means all origins are allowed.

## Comfy Desktop
1. In the Comfy Desktop application, once started, open the top bar "Comfy Desktop" button.
2. Select the "ComfyUI" entry in the "Instances" left panel.
3. Open the "Startup Args" tab.
4. In the "StartUp Arguments" control, type `--port <portNumber> --enable-cors-header * --enable-manager` where `<portNumber>` is the port number you wish the internal Comfy Desktop back-end HTTP to listen to, by default `8188`.
5. Press the "Start" or "Restart to apply changes" button.

From here you can start using the Picteus "ComfyUI" extension.

# Settings
- The `URL` indicates the URL of the ComfyUI / Comfy Desktop server. By default, the server listens to `http://127.0.0.1:8188`. Replace `8188` by the value you provided to `<portNumber>` in the prerequisites.
- The `Directory path` indicates the location of the directory where ComfyUI / Comfy Desktop Python code resides.
  - For Comfy Desktop, by default, it is installed in — where `<user>` represents the current user's login:
    - `C:\Users\<username>\ComfyUI-Installs\ComfyUI` on Windows, 
    - `/Users/<username>/ComfyUI-Installs/ComfyUI` on macOS,
    - `/home/<username>/ComfyUI-Installs/ComfyUI` on Linux.

# Commands

## openInComfyUi
This opens the image workflow both in ComfyUI / Comfy Desktop and in the Picteus sidebar.
