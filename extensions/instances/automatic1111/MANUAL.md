# Summary
This extension offers a bridge between Picteus and [Automatic1111 / Stable Diffusion web UI](https://github.com/automatic1111/stable-diffusion-webui).

Whenever an image is indexed, if that image was generated via Automatic, it stores its generation parameters in the database, which is accessible from an image detail page. This does not require any other third-party software, and it works even if Automatic1111 is not installed.
