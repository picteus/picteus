# Summary
This extension connects Picteus with [Google Gemini](https://gemini.google.com).

Whenever a new image is created (or when manually requested), it inspects it to assess whether it was generated via Gemini / Nano Banana.

# Settings

- The `API Key` specifies the [Google Gemini API key](https://aistudio.google.com/api-keys) to use when interacting with Gemini via web services.

# Commands

## generate
Generates an image from a prompt, following an aspect ratio, using one the image generative models exposed through Gemini.

## modify
Generates an image from a prompt and with reference images, following an aspect ratio, using one the image generative models exposed through Gemini.
